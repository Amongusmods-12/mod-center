How to Install the Mod Files

1. Download the mod pack using the “Install Mods” button.

2. Extract the ZIP file using WinRAR or 7‑Zip.

3. Open your Among Us folder.

4. Drag all mod files into the Among Us folder.

5. If asked to replace files, click YES.

6. Launch the game — the mods should load automatically.

7. If the game crashes, verify your game files and reinstall the mod pack.
