How to Use the Mod Files

01 Download the Mod Pack Required First Get the full mod bundle from the 'Install Mods' button on the website. Click the Install Mods button on the homepage A file named mods.zip will start downloading Save it somewhere easy to find (Desktop or Downloads) 02 Extract the ZIP File You need to unzip the file before using the mods. Right‑click mods.zip Select Extract All… Choose a folder to extract to After extraction, you will see multiple mod ZIPs or folders inside 03 Locate Your Game Folder Important You must place the mod files inside the correct game directory. Open your game installation folder If it's Among Us (Epic Games), the folder is usually: C:\Program Files\Epic Games\AmongUs If you installed the game somewhere else, go to that location instead 04 Create or Open the Mods Folder This is where all mod files must be placed. Inside the game folder, look for a folder named BepInEx If it exists, open it and find plugins If it does NOT exist, create a new folder named BepInEx, then inside it create another folder named plugins 05 Move the Mod Files Place all mod files into the correct folder so the game can load them. Open the extracted mod files from Step 2 Drag ALL mod DLLs or mod folders into: Among Us → BepInEx → plugins Make sure the files are NOT still zipped The folder should now contain multiple .dll files 06 Launch the Game Final Step Start the game to confirm the mods are working. Open Among Us normally If the mods installed correctly, you will see a BepInEx console window or a mod menu Join or create a lobby to test everything
